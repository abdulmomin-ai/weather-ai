 WeatherAI

A production-style weather dashboard built with Python and Flask.

 Features

- City-based weather search
- Geocoding
- Current weather conditions
- 7-day forecast
- Weather condition mapping
- Human-readable forecast dates
- Error handling
- Logging
- Automated tests
- Responsive UI
- Animated interface

 Tech Stack

- Python
- Flask
- Requests
- Jinja2
- HTML
- CSS
- Open-Meteo API
- Pytest
